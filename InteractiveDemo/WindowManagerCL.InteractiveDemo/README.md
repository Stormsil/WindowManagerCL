# WindowManagerCL - Интерактивное Демо

Интерактивное консольное приложение для тестирования всех функций библиотеки WindowManagerCL.

## Запуск

```bash
cd InteractiveDemo/WindowManagerCL.InteractiveDemo
dotnet run
```

## Возможности

### 1. Поиск окон
- **Точный заголовок** - поиск окна по точному совпадению заголовка
- **Частичный заголовок** - поиск окна по части заголовка
- **Регулярное выражение** - гибкий поиск с использованием regex
- **Имя класса** - поиск по классу окна (например, "Notepad")
- **Process ID** - поиск окон по ID процесса
- **HWND** - обернуть существующий хэндл окна

### 2. Управление состоянием
- **Активировать** - вывести окно на передний план
- **Свернуть** - минимизировать окно
- **Развернуть** - максимизировать окно
- **Восстановить** - вернуть нормальное состояние
- **Закрыть** - закрыть окно

### 3. Позиция и размер
- **Переместить** - изменить позицию окна
- **Изменить размер** - изменить размер окна
- **Установить границы** - установить позицию и размер одновременно

### 4. Информация об окне
Просмотр детальной информации о выбранном окне:
- Заголовок и класс
- Handle (HWND)
- Process ID
- Состояние (Normal, Minimized, Maximized)
- Границы (X, Y, Width, Height)
- Видимость и валидность
- Родительское окно

### 5. Иерархия окон
- **Родительское окно** - показать родительское окно
- **Дочерние окна** - список всех дочерних окон
- **Поиск дочернего окна** - найти дочернее окно по классу

### 6. Список всех окон
- Показать все окна в системе
- Фильтровать только видимые окна
- Выбрать окно для работы

### 7. Примеры использования
Готовые примеры для быстрого старта:
- **Notepad** - найти и развернуть Notepad
- **Chrome** - найти все окна Chrome
- **Calculator** - изменить размер калькулятора
- **Активное окно** - получить информацию о текущем активном окне

## Использование

1. Запустите приложение
2. Выберите функцию из главного меню (1-7)
3. Следуйте инструкциям на экране
4. Для большинства операций сначала нужно выбрать окно через меню "Поиск окон"

## Пример сценария

```
1. Выберите "1. Поиск окон"
2. Выберите "2. Поиск по частичному заголовку"
3. Введите "Chrome"
4. Окно найдено и установлено как текущее
5. Вернитесь в главное меню
6. Выберите "2. Управление состоянием окна"
7. Выберите "3. Развернуть"
8. Окно Chrome развернуто!
```

## Советы

- **Текущее окно** отображается в главном меню вверху
- Используйте **Try-примеры** (пункт 7) для быстрой проверки функций
- Для поиска можно использовать **regex** для сложных паттернов
- Все операции имеют **обработку ошибок** с понятными сообщениями

## Требования

- .NET 9.0 или выше
- Windows 10 версии 1809 или новее
- Запущенные окна для тестирования (Notepad, Chrome, Calculator и т.д.)

## Цветовая схема

- 🟢 **Зеленый** - успешные операции
- 🔴 **Красный** - ошибки
- 🟡 **Желтый** - заголовки меню
- 🔵 **Cyan** - подзаголовки
- ⚪ **Серый** - информация

Enjoy testing! 🚀
